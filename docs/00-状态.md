三条设计要点（都由数据决定，不是拍脑袋）：

  · 关键词判定 = **主判据**（免费、确定、已知措辞上全对）
  · LLM 裁判   = **独立交叉校验**，**不参与 `correct` 的计算**
    —— 它的成本与抖动还没在规模上量清楚（自一致 8/8，但样本很小），
       直接当主判据等于把一个没量清的误差源引进所有数字
  · 两者分歧 → **单列出来并带原文**（#16/#21 正是这样被发现的）

⚠️ **裁判失败（unknown / error）绝不算作一致** —— 返回 `None`（不可用）。
   把"没测出来"伪装成"测出来一致"是本项目反复在防的那类静默失真。
   这条有专门的用例与变异体守着。

### D6 已完成 ✅ —— 三个专职 Agent（信息隔离）

**核心不是"三个 Agent 更聪明"，而是"每个 Agent 客观上存在盲区"。**

理由：如果每个 Agent 都能看到全部数据，"多 Agent"就只是**同一份数据问三遍**——
成本三倍、信息零增益。只有让每个角色的结论都是**不完整的**，协作才产生真实价值。

**交付物**

| 文件 | 职责 |
|---|---|
| `src/rca/agents/roles.py` | LOGS / METRICS / CHANGE 三角色定义 + 各自的 `system_prompt` + `OUTPUT_CONTRACT` |
| `src/rca/agents/specialist.py` | `SpecialistAgent`、`investigate_all(parallel=True)`、`Hypothesis` |
| `src/rca/tools.py` | `RestrictedToolBox` —— **隔离不是靠 prompt 写"你只能看日志"，是靠工具面真的只开一个** |
| `scripts/run_specialists.py` | 单角色可独立运行（用于观察"盲区"是否真实存在） |

**结构上的保证**

- 每个专职 Agent 拿到的是 `RestrictedToolBox`，**只挂载自己那一个工具**；
  越权调用会被拒绝并计入 `denied_tool_calls`（该值应当恒为 0）。
- `OUTPUT_CONTRACT` 强制要求填 `needs_from_others` ——
  **每个 Agent 必须显式说出"我还缺什么信息"**，这是"盲区真实存在"的可观测证据，
  也是第二轮交叉质证的问题来源。

| Shell | 只有 Windows PowerShell 5.1（**无 `pwsh`**）、**无 `make`** |
| 时区 | 容器已统一到 `Asia/Shanghai` |

### ⚠️ 三条踩过的坑（同一个编码机制，已造成 4 次不同后果）

1. **可执行脚本必须纯 ASCII**（`.ps1` / `.bat` / `.cmd` / `Makefile`）。
   PowerShell 5.1 会把 UTF-8 无 BOM 的脚本按 GBK 读，
   中文被 mangle 后**会破坏语法**。见 `docs/harness-log.md` #1 #2。
2. **中文路径下不要用 PowerShell 读写文本文件**，用 `read`/`write`/`edit` 工具。
   （顺带：`Get-Content` 读 UTF-8 文件时连**行号都是错的**，别用它定位行。）
3. **Python 脚本要打印非 ASCII，必须给 stdout 兜底**：

   ```python
   try:
       sys.stdout.reconfigure(encoding="utf-8", errors="replace")
   except Exception:
       pass
   ```

   stdout 接到**管道/文件**时会退回本地编码 GBK，打印 emoji 直接抛
   `UnicodeEncodeError`，**整段输出和退出码一起丢掉**。
   `encoding` 和 `errors` **缺一不可**（只加 `errors` 不崩了，但输出仍是 GBK 字节、全是乱码）。
   实测对照表见 `AGENTS.md` 第 4 条"坑 4"；自动检查见 `test_regression_p4_*`。

## 七、更新纪律

**每完成一个里程碑，必须：**

1. 更新本文件的「一、当前进度」与「二、下一步」
2. 如有新决策 → 写一条 `docs/adr/`
3. 如有新封堵的错误 → 追加 `docs/harness-log.md`
4. `git commit`，并在提交信息里写上里程碑编号

**为什么这么严**：上下文会随对话变长而失真，但**文件不会**。
把状态写进文件，等于把"记忆"外置——新会话、新代理、甚至你自己一周后回来，
读三个文件就能接着干。
