# ADR-0006：不存在硬删除 —— 把「不可逆」变成「可逆」

- **日期**：2026-09-25（D15 补记；决定发生在 D0，事故发生在 D0 之前）
- **状态**：已采纳
- **背景（真实事故）**：我在一次清理中**误删了一个工作目录之外的真实目录**，
  **不可恢复**。事后复盘，四道本该拦住它的环节全部失效：

  1. 命令写错了路径（人的注意力）；
  2. `-Force` **绕过了回收站**（工具的默认保护）；
  3. 磁盘**没有卷影副本/快照**（操作系统的兜底）；
  4. 没有"删除前先看清单"的步骤（流程）。

  **关键认识**：根因不是"守卫没拦住"，而是**物理层面根本没有留下退路**。
  只要"不可逆"这件事成立，任何一环疏忽都是终局。

---

## 决定 1：策略执行点**不提供**删除动作，只有"移入隔离区"

**决定**：`src/rca/policy/` 的动作面里没有 `delete`；
"删除"被表达为 **移入隔离区（quarantine）+ TTL + 可还原**，并写审计日志。

**理由**：不能把正解寄托在"守住所有不可逆操作"上（那要求守卫 100% 正确），
而要**让操作本身可逆** —— 这样守卫的正确率就不再是单点故障。

**代价**：隔离区需要清理策略（否则无限增长）；"删除"在语义上分裂成两个动作
（移入 + 到期清理），接口变复杂。

---

## 决定 2：仓库层面**禁止删除**（包括临时目录）

**决定**：本项目约束里有一条硬规矩（`AGENTS.md` 第 0 条）：
**不许删除任何文件或目录，连临时目录也不许**；需要"清理"的场景一律改成覆盖写/另存。

**理由**：把"不可逆"从**工作流**里去掉，而不是靠我每次都小心。
这条规矩在本次交付里被反复用到：变异副本**只新建从不删除**（副本本身就是证据留痕）、
证据文件覆盖前先 `Copy-Item` 另存。

**代价**：磁盘会累积（变异副本、runs/ 下的多次运行）；有些"看起来该删"的东西一直留着。

---

## 决定 3：如实标注"这条机制**未接到 Agent 路径**"

**决定**：`src/rca/policy/` 已实现且有 27 条用例，但**Agent 路径上一次都没调用它**
（工具面目前是 3 个**只读**工具）；因此 **FR-2.1「无旁路保证」尚未成立**。
这一点必须写在对外文档里（见 ADR-0001 决定 2）。

**理由**：机制建好了 ≠ 命题成立了。把"未接线"写出来，比让读者以为
"任何不可逆操作都会经过确定性边界"要诚实得多 —— 而后者正是 harness-log #41 的现场。
